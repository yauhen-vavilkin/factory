Project is not configured

Factory does not know the repository.

1. Add an entry under factory.dev-factory.repositories in config/developer-repositories.yaml. Put the repository name where it says <repository>:

<repository>:
  source-repo: folio-org/<repository>
  base-branch: master
  build-image: maven:3.9-eclipse-temurin-21
  verification-plan: java21-unit
  jira-projects: [PROJECT]
  delivery:
    repository: folio-org/<repository>

2. Restart Factory so it reads the file again:

docker compose restart factory

3. Click Scan Jira. The task becomes available.
