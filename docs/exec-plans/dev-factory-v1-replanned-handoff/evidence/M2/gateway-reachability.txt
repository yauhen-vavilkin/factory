Pi acceptance starts a scripted local gateway and routes the real Pi process
through it; the Maven trigger evidence is in mvn-verify-excerpt.log.
The shipped pi profile is credential-free (spring.ai.model.chat=none), uses
Docker, and targets FACTORY_PI_GATEWAY_URL with a host-gateway default.
No ANTHROPIC_API_KEY is read on this path; the smoke gateway recorded three
scripted model requests and paid_calls=0.
