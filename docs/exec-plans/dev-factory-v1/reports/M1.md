## Implemented capability

- Published `TaskRequest/v1` JSON Schema and strict YAML/JSON parser. The parser preserves exact raw
  task text, explicitly adapts the historical eight-key format, requires an explicit base ref or full
  SHA, limits input to 256 KiB, enforces strict UTF-8, rejects duplicate/unknown schema keys, multiple
  documents, unsafe task-owned configuration, non-regular files, and symlinks.
- Added atomic file submission (`.partial` then same-filesystem rename), JSON reject/block/admission
  receipts, semantic hash plus `runKey` identity, and retryable handling for repository, DB, and routing
  failures. The existing `(flow_id, admission_key)` database constraint remains authoritative.
- Added the trusted four-repository catalog, exact aliases/project/component mappings, HTTPS origin
  validation, fixed-host GitHub reads with redirects disabled, separate branch and full-SHA handling,
  and persistence of the resolved exact SHA in the admitted payload.
- Added bounded static POM/wrapper/package/lock inspection with hardened XML parsing. No target Maven,
  npm, or repository script is invoked on the Factory host. Node is explicitly `UNSUPPORTED_PROFILE`;
  unknown Java, inherited framework versions, and Docker requirements remain visible.
- Added code-owned `ExecutionProfile` and `VerificationPlan` catalogs. Task text cannot supply commands,
  images, mounts, credentials, network policy, workdir, or stronger effective budgets.
- Added `ResolvedIntent/v1`, `ExecutionContract/v1`, canonical hashes, immutable configuration and
  preparation references, source/acceptance provenance, unknowns, policies, and budgets. Contract
  freezing rejects missing or non-immutable source/image/seed/baseline/config hashes and material
  unknowns. The compatible harness view retains raw task text and receives checks only from the trusted
  frozen plan.
- Added `resolve-task` diagnostic API/CLI and atomic `submit` CLI. An admitted M1 intent is explicitly
  blocked before sandbox/model/build until later preparation supplies real immutable references.
