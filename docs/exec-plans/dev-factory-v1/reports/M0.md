## Implemented baseline

- Pinned Maven Wrapper 3.3.4 / Maven 3.9.16 and repository-local `.factory/cache/maven-repository`; the POM versions remain Java 21, Spring Boot 4.0.7, Spring AI 2.0.0, Testcontainers 2.0.5, and docker-java 3.7.1.
- Tagged infrastructure tests separately from pure tests, retained scripted `eval-pack` tags, and reserved the excluded `live` tag for explicit opt-in diagnostics. Each validation command requires a non-zero selection; Docker absence is an explicit integration blocker.
- Added the explicit `offline` profile and a deterministic `OfflineScriptedChatModel` with no HTTP/provider delegate. Startup tests prove zero model calls, and fake connector credentials remain unconfigured because local external writes are disabled.
- Factory runs as a loopback-bound host JVM; Compose contains only loopback-bound PostgreSQL with health checks, a random 0600 password file, and bind-mounted persistent storage.
- `.factory` owns private config, secrets, Maven cache, logs, PID/lock state, artifacts, recovery data, inbox, sandboxes, and PostgreSQL data. Directories are 0700; config/secret/PID/log files are 0600.
- Engine defaults and effective YAML are `maxConcurrentExecutions=1`, `worker-threads=1`, and `batch-size=1`; the poller checks running capacity before claiming work.
- `scripts/factory` implements `init`, `infra up/down`, `doctor --offline`, `start --mode offline|live`, `stop`, and the three validation suites. PID/lock/port checks reject duplicates, and missing live credentials fail before the JVM or a provider request starts.
